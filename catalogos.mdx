Um **catálogo** é a vitrine de produtos que você compartilha com seus clientes. Você pode ter vários catálogos (ex: um por categoria, por sazonalidade, por público) — o plano gratuito já permite vários.

<Info>
Nunca criou um catálogo? Veja o passo a passo em [Primeiros Passos](/primeiros-passos/criando-primeiro-catalogo).
</Info>

## Selecionando produtos

Ao criar ou editar um catálogo, você escolhe como ele exibe seus produtos:

| Método | Como funciona |
|---|---|
| **Todos** | Exibe todo o catálogo de produtos ativos automaticamente |
| **Por categoria** | Você marca quais categorias (e subcategorias) entram |
| **Selecionar produtos** | Você escolhe produto a produto |

## Descontos e responsáveis

- **Desconto do catálogo**: um valor em R$ aplicado a todos os produtos daquele catálogo com um clique — útil para campanhas temporárias.
- **Responsáveis**: um ou mais membros da equipe que recebem os pedidos desse catálogo. Com mais de um responsável, os pedidos são distribuídos em rodízio; um cliente que já tem responsável continua com ele.
- **Período**: catálogos podem ter data de início e fim (útil para campanhas como "Dia dos Namorados" ou "Copa").

## Editor visual

Clique em **Abrir editor de personalização** dentro de um catálogo salvo para montar a página que o cliente vê. O editor funciona por seções que você adiciona, remove e reordena:

| Seção | Descrição |
|---|---|
| **Cabeçalho** | Logo, busca e menu — fixo |
| **Banner Slider** | Imagem em destaque com título e botão |
| **Banner Grid** | Vários banners lado a lado |
| **Linqui Stories** | Vídeos/fotos estilo Instagram Stories no topo do catálogo |
| **Categorias** | Slider com as categorias do catálogo |
| **Produtos em destaque** | Slider de destaques e lançamentos |
| **Lista de produtos** | Grade principal de produtos |
| **Rodapé** | Fixo, com informações da empresa |

Você pode alternar entre **preview desktop e mobile** no topo do editor antes de publicar.

### Temas predefinidos

Clique em **Tema** para aplicar um estilo visual completo (cores, tipografia, formas) de uma vez:

![Temas predefinidos do catálogo](https://raw.githubusercontent.com/wellingtonsantos/linqui-docs-media/main/temas-catalogo.png)

| Tema | Estilo |
|---|---|
| Linqui (padrão) | Identidade original, equilibrada e neutra |
| Minimal Monocromático | Preto e branco, formas suaves |
| Boutique Elegante | Serifa refinada, tons quentes |
| Vivo Moderno | Acentos vibrantes |
| Natural Orgânico | Tons terrosos, formas fluidas |
| Tech Dark | Fundo escuro, ciano elétrico |
| Pastel Suave | Rosa pastel, fontes amigáveis |
| Editorial Luxe | Serifa display, dourado discreto |
| Urban Bold | Tipografia condensada, laranja |

Você também pode usar **Usar tema global** para aplicar o mesmo tema em todos os seus catálogos de uma vez, em vez de configurar um por um.

## Publicando

Depois de montar o catálogo, clique em **Publicar** no canto superior direito do editor. Você recebe um link (`loja.linqui.app/...`) pronto para compartilhar. É possível usar um **domínio próprio** — veja [Configurações](/configuracoes).

## Catálogos inativos

Catálogos que você desativa (mas não exclui) ficam na aba **Inativos**, dentro de Catálogos. Eles saem do ar mas mantêm toda a configuração para reativar quando quiser.
